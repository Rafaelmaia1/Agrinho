Olá, pequeno(a) programador(a)! 👋

Parece difícil? Não se preocupe! Vamos fazer **um passo de cada vez**, com calma. 😊

```

## 🤖 PASSO 1 — Pedindo o Código para o Gemini (Inteligência Artificial)

O **Gemini** é uma inteligência artificial do Google que consegue **criar código de site para você** só de você pedir com palavras!

### Como fazer:

1. Abra o navegador (Chrome, Firefox, Edge…) e acesse: **[gemini.google.com](https://gemini.google.com)**

2. Se pedir para fazer login, entre com sua conta do Google (a mesma do Gmail).

3. Na caixinha de texto, **escreva o que você quer que o site faça**. Por exemplo:

   > *"Crie uma página web com HTML, CSS e JavaScript sobre o tema Agrinho. O site deve ter um título bonito, um texto explicando a importância do campo para a cidade, e um botão que muda a cor de fundo da página."*

4. Clique em **Enviar** (o botão de seta ➡️) e **espere alguns segundos**.

5. O Gemini vai responder com **três blocos de código**:
   - Um bloco de **HTML** (começa com `<!DOCTYPE html>` ou `<html>`)
   - Um bloco de **CSS** (começa com `body {` ou `* {`)
   - Um bloco de **JavaScript** (começa com `function` ou `document.`)

6. **Copie cada bloco** clicando no botão de copiar que aparece no canto de cada um. 📋

> 💡 **Dica:** Se quiser um site mais bonito, peça mais detalhes! Exemplo: *"Use cores verdes e marrons, adicione emojis e deixe o visual moderno."*

## 💻 PASSO 2 — Testando o Código no OneCompiler

O **OneCompiler** é como um "parquinho" para testar código. Você cola o código lá e ele mostra o site funcionando na tela — sem precisar instalar nada!

### Como fazer:

1. Acesse: **[onecompiler.com/html](https://onecompiler.com/html)**

2. A página vai abrir com **três abas** no editor:
   - **HTML** → O esqueleto do site (textos, imagens, botões)
   - **CSS** → A roupa do site (cores, tamanhos, visual)
   - **JS** → O cérebro do site (o que acontece quando você clica em algo)

3. **Clique na aba HTML**, selecione tudo com `Ctrl + A` e apague. Cole o código HTML que o Gemini gerou.

4. **Clique na aba CSS**, selecione tudo com `Ctrl + A` e apague. Cole o código CSS que o Gemini gerou.

5. **Clique na aba JS**, selecione tudo com `Ctrl + A` e apague. Cole o código JavaScript que o Gemini gerou.

6. Agora clique no botão verde **▶ Run** no topo da página!

7. 🎉 Um painel vai aparecer mostrando **o seu site funcionando!**

> 💡 **Dica:** Se algo não aparecer certo, volte ao Gemini e peça para ele corrigir. Copie o erro que apareceu e diga: *"Este erro apareceu: [cole o erro aqui]. Pode corrigir o código?"*

### Salvando no OneCompiler (opcional):

- Clique em **Save** ou pressione `Ctrl + S`
- Crie uma conta gratuita se pedir
- Você receberá um link para compartilhar com amigos! 🔗

## 🐱 PASSO 3 — Criando sua Conta no GitHub

O **GitHub** é o lugar onde programadores guardam e compartilham seus códigos. É como uma "nuvem" só para sites e programas!

### Como criar sua conta:

1. Acesse: **[github.com](https://github.com)**

2. Clique em **Sign up** (Criar conta) no canto superior direito.

3. Preencha:
   - ✉️ Seu e-mail
   - 🔒 Uma senha (anote em algum lugar!)
   - 👤 Um nome de usuário (este nome vai aparecer no endereço do seu site!)

4. O GitHub vai enviar um **código de confirmação** para o seu e-mail. Abra o e-mail, copie o código e cole no GitHub.

5. Responda as perguntas de configuração (pode clicar em **Skip** para pular as opções pagas).

6. Pronto! Você tem uma conta no GitHub! 🎊

---

## 📁 PASSO 4 — Criando um Repositório (A pasta do seu projeto)

Um **repositório** é como uma pasta especial onde ficam os arquivos do seu site.

### Como criar:

1. No GitHub, clique no botão **verde "New"** (ou no `+` no canto superior direito e depois em *New repository*).

2. Preencha o campo **"Repository name"** com o nome do seu projeto. Exemplo: `Agrinho`

   > ⚠️ **Importante:** Use o **mesmo nome que você quer no endereço do site**, sem espaços! Use `-` no lugar de espaço se precisar.

3. Deixe marcado como **Public** (público), para que o site possa ser visto por todos.

4. Marque a caixinha **"Add a README file"** ✅

5. Clique em **Create repository** (Criar repositório).

6. Sua pasta está criada! Agora ela aparece na tela. 🗂️

---

## 📤 PASSO 5 — Colocando os Arquivos no GitHub

Agora você vai colocar os arquivos HTML, CSS e JavaScript no seu repositório!

### Criando o arquivo HTML:

1. Dentro do repositório, clique em **"Add file"** → **"Create new file"**.

2. No campo do nome do arquivo (onde está escrito *"Name your file..."*), escreva: `index.html`

3. No espaço grande abaixo, **cole todo o código HTML** gerado pelo Gemini.

4. Lá embaixo da página, clique no botão verde **"Commit changes"** (Salvar alterações).

5. Uma janeinha vai aparecer, clique em **"Commit changes"** novamente para confirmar. ✅

### Criando o arquivo CSS:

1. Clique em **"Add file"** → **"Create new file"** novamente.

2. No nome do arquivo, escreva: `styles.css`

3. Cole todo o código CSS.

4. Clique em **"Commit changes"** → **"Commit changes"**. ✅

### Criando o arquivo JavaScript:

1. Clique em **"Add file"** → **"Create new file"** novamente.

2. No nome do arquivo, escreva: `script.js`

3. Cole todo o código JavaScript.

4. Clique em **"Commit changes"** → **"Commit changes"**. ✅

> 💡 **Dica:** Certifique-se que no seu arquivo `index.html` os links para CSS e JS estão corretos! Deve aparecer algo assim:
> ```html
> <link rel="stylesheet" href="styles.css">
> <script src="script.js"></script>
> ```

## 🌐 PASSO 6 — Publicando o Site com GitHub Pages

Chegou a hora mais emocionante: **colocar o site no ar para todo mundo acessar!**

### Como ativar o GitHub Pages:

1. No seu repositório, clique em **"Settings"** (Configurações) — é o ícone de engrenagem ⚙️ no menu do topo.

2. No menu da esquerda, procure e clique em **"Pages"**.

3. Em **"Source"** (Fonte), clique no menu que diz *"None"* e selecione **"main"**.

4. Clique em **"Save"** (Salvar).

5. Aguarde cerca de **1 a 2 minutos** ⏳

6. A página vai mostrar uma mensagem verde com o endereço do seu site! Vai ser algo assim:

   ```
   https://SEU-USUARIO.github.io/NOME-DO-REPOSITÓRIO/
   ```
   
7. **Clique no link e veja seu site no ar!** 🚀🎉

## 🆘 Algo deu errado? Soluções rápidas!

| Problema | Solução |
|---|---|
| O site não aparece no OneCompiler | Verifique se colou o código na aba certa (HTML, CSS ou JS) |
| O CSS não está funcionando | Confirme que o arquivo se chama `styles.css` e que o HTML tem `<link rel="stylesheet" href="styles.css">` |
| O GitHub Pages não apareceu | Espere mais alguns minutos e atualize a página de Settings > Pages |
| Deu erro no código | Copie o erro e peça ao Gemini para corrigir! |
| Esqueceu a senha do GitHub | Clique em "Forgot password?" na tela de login |
