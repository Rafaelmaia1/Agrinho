🌿 Projeto Agrinho: Criando Seu Próprio Portal do Futuro da Agronomia!

Olá, futuro(a) programador(a)! 👋 Bem-vindo(a) ao guia passo a passo para construir e rodar o site **Agrinho**. Este site foi feito para espalhar ideias incríveis sobre como a tecnologia e o carinho com a Terra podem transformar o nosso futuro. 

Prepare-se para se tornar um(a) mestre dos códigos! Segui cada passo abaixo e veja a mágica acontecer na tela do seu computador. 🚀

---

## 🎒 Passo 1: Preparando a sua Caixa de Ferramentas (Instalar o VS Code)

Para escrever nossos códigos, precisamos de um aplicativo especial chamado **Visual Studio Code** (ou simplesmente **VS Code**). Ele é como um caderno mágico que entende linguagens de computador!

1. **Baixe o VS Code:** Peça ajuda para um adulto ou clique diretamente no site oficial: [code.visualstudio.com](https://code.visualstudio.com/).
2. **Instale:** Clique no botão azul grande escrito **"Download for..."** (vai depender se o seu computador é Windows ou Mac). Abra o arquivo que baixou e clique em "Avançar/Next" até terminar.
3. **Abra o programa:** Quando terminar, clique no ícone azul do VS Code que apareceu na sua área de trabalho!

---

## 🎨 Passo 2: Turbinando o seu Editor (Instalar Extensões)

As extensões são como superpoderes que adicionamos ao VS Code para facilitar nossa vida! Vamos instalar a extensão mais importante de todas: a **Live Server** (ela cria um botão mágico para ver o site funcionando ao vivo!).

1. Na lateral esquerda do VS Code, procure por um ícone que parece **4 quadradinhos juntos** (o de cima está voando). Clique nele! (Ou aperte `Ctrl + Shift + X`).
2. Na barra de pesquisa que apareceu no topo, digite: `Live Server`.
3. Procure pela extensão feita por um criador chamado *Ritwick Dey* e clique no botão verde **Install** (Instalar).
4. Pronto! O superpoder está ativo.

---

## 📁 Passo 3: Criando a Pasta do Projeto

Computadores gostam de organização! Vamos criar uma casinha para colocar os arquivos do nosso site.

1. Vá na Área de Trabalho do seu computador, clique com o botão direito do mouse, escolha **Novo** e depois **Pasta**.
2. Dê o nome de `projeto-agrinho` para essa pasta.
3. Agora volte para o VS Code. No menu do topo, clique em **File** (Arquivo) e depois em **Open Folder** (Abrir Pasta).
4. Escolha a pasta `projeto-agrinho` que você acabou de criar e clique em selecionar.

---

## 📝 Passo 4: Adicionando os Arquivos de Código

Agora que a pasta está aberta no VS Code, vamos criar 3 arquivos fundamentais que dão vida à internet. Na lateral esquerda, clique no ícone de uma folha de papel com um sinal de mais (`+`) para criar cada arquivo com os nomes exatos abaixo:

### 1️⃣ O Esqueleto: `index.html`
O HTML cuida de todos os textos, títulos e imagens do site. É a estrutura dele!
* Crie o arquivo chamado `index.html`.
* Copie todo o código HTML do seu projeto e cole dentro dele. Salve apertando `Ctrl + S`.

### 2️⃣ A Roupa e as Cores: `styles.css`
O CSS é o estilista do site! Ele decide as cores do Modo Claro, do Modo Escuro, o tamanho das letras e deixa tudo alinhado e bonito.
* Crie o arquivo chamado `styles.css`.
* Copie as regras do CSS e cole aqui dentro. Salve apertando `Ctrl + S`.

### 3️⃣ O Cérebro: `java.js`
O JavaScript dá vida e interatividade ao site! Ele faz o botão do Modo Escuro funcionar, aumenta e diminui a letra e até lê o texto em voz alta para quem precisa!
* Crie o arquivo chamado `java.js`.
* Copie o código javascript e cole aqui dentro. Salve apertando `Ctrl + S`.

---

## 🚀 Passo 5: A Hora do Show (Rodar o Site!)

Agora que os três arquivos estão salvos e na mesma pasta, vamos ver o seu site funcionar de verdade no navegador de internet!

1. Clique no arquivo `index.html` na lateral esquerda para deixar ele aberto na sua tela.
2. Olhe bem para o cantinho inferior direito do VS Code (bem no rodapé da janela). Você verá um botão com uma anteninha escrito **Go Live**.
3. **Clique em Go Live!** ✨
4. Uma nova aba vai se abrir automaticamente no seu navegador (como o Google Chrome ou Edge) mostrando o seu site lindão!

---

## 🎮 Como Usar a Barra de Acessibilidade Flutuante?
No cantinho inferior direito da tela do seu site, um menu redondo muito legal vai aparecer com vários botões mágicos:
* **A+ e A-:** Aumentam ou diminuem o tamanho das letras para quem tem dificuldade de ler coisas miúdas.
* **A:** Volta a letra para o tamanho original.
* **🌙 (Lua):** Transforma o site para o **Modo Escuro** instantaneamente (ótimo para ler à noite sem cansar os olhos!). Clicando de novo ele volta para o Modo Claro.
* **🔊 (Som):** O computador começa a ler todos os artigos do site em voz alta para você!
* **■ (Quadrado):** Para a leitura de voz imediatamente.

---

## ⭐ Dica de Ouro para Treinar!
Tente mudar alguma palavra do texto dentro do seu arquivo `index.html` no VS Code e salve (`Ctrl + S`). Você vai ver que, graças ao **Live Server**, o seu site na internet se atualiza sozinho no mesmo segundo!
